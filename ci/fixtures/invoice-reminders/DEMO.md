# Invoice reminders demonstration

This is a fictional worked example of Exacly, based on the repository's existing
invoice-reminders model. The report, date and revision are illustrative. They are
not evidence of a real reminder service, a live CI run, or a deployment.

The build derives the config from the existing example, changes the environment
to `demo`, and marks `REQ-001` active with an illustrative review date. Other
records keep their original intent. The canonical source example stays unchanged.

`state/demo.json` is generated by Exacly's refresh observer from
`sample-junit.xml`, using context `demo`, revision `invoice-reminders-demo-v1` and
the illustrative timestamp `2026-10-28T12:00:00Z`. All three selected sample cases
pass. There is no delivery observation, so passing verification does not imply
that anything has shipped. The sample cases illustrate part of the requirement;
their names do not establish complete acceptance coverage or test honesty.

From this extracted folder, inspect the requirement with the published package:

```sh
uvx exacly show REQ-001 -m .
```

The small XML report is included so you can inspect what the observer read.
